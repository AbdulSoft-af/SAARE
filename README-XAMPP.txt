SAARE — د افغانستان د مخابراتو لارښود

په XAMPP کې چلول:
۱) دا بشپړ فولډر له ZIP څخه راوباسئ.
۲) فولډر د C:\xampp\htdocs\SAARE\ دننه کېږدئ.
۳) په XAMPP Control Panel کې Apache فعال کړئ.
۴) په براوزر کې http://localhost/SAARE/ پرانیزئ.

دا static وېب‌پاڼه ده؛ PHP، MySQL او انټرنېټ د محلي چلولو لپاره نه غواړي. د ویب‌پاڼې CSS او JavaScript فایلونه په assets/css او assets/js کې دي، نو د اپلوډ پر مهال ټول فولډرونه هم وساتئ.

آنلاین خپرول:
ټولې فایلونه او د assets فولډرونه د هاست اصلي فولډر ته اپلوډ کړئ. index.html باید په اصلي فولډر کې وي. د XAMPP لپاره د ZIP دننه project فولډر ته د SAARE نوم ورکول اسانه دي.

معلومات:
کڅوړې له رسمي شبکيزو سرچینو سره تړل شوې دي؛ نرخ، شرایط او کوډونه بدلېدای شي. دا سایټ ژوندی نرخ نه رااخلي. د فعالولو مخکې د هر کارت رسمي سرچینه وګورئ. د ولایت انتخاب یوازې د سیمې پوښښ د تایید یادونه ښيي؛ د هرې شبکې موجودیت نه تضمینوي.

د ژبې انتخاب: پښتو، دري او انګلیسي.
